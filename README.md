# ⚡ OXIGÊNIO — Academia de Musculação de Alta Performance

> *"Exale uma Energia Diferente e Única"*

**OXIGÊNIO** é uma landing page institucional e interativa criada para uma academia de musculação de alta performance, projetada para atletas e praticantes que buscam hipertrofia, resistência e foco extremo. O projeto destaca-se por entregar uma experiência imersiva e responsiva construída **100% em CSS Puro (Zero JavaScript)**.

---

## 👁️ Visão Geral

A **OXIGÊNIO** redefine o conceito de academias tradicionais. O projeto reflete um ambiente forjado para superação de limites, combinando um tom de marca impositivo e motivacional a uma arquitetura web leve e extremamente veloz.

* **Diferencial**: Alta interatividade e dinamismo sem depender de nenhuma linha de código JavaScript ou bibliotecas externas.
* **Propósito**: Converter visitantes em membros do time por meio de uma navegação fluida, apresentação clara de planos e escolha personalizada de treinos.
* **Público-alvo**: Atletas, praticantes avançados de musculação, entusiastas do fitness de alto rendimento e desenvolvedores buscando referências em CSS avançado.

---

## 🔥 Características Principais

* **Hero Section com Núcleo de Energia (O₂)**: Animação bioluminescente pulsante que simula a frequência cardíaca e o fluxo de oxigênio do atleta em treino intenso.
* **Seletor Interativo de Treinos**: Alternador dinamizado por CSS que permite ao usuário navegar entre três modalidades de treino (*Força Bruta*, *Cardio Extremo* e *Box Funcional*).
* **Grid de Planos com Efeito Glow**: Apresentação clara das assinaturas (Basic, Pro Energy e Elite), destacando visualmente o plano recomendado através de bordas incandescentes e sombras projetadas.
* **Estética Dark-Industrial**: Design visual marcante baseado no tema escuro, contrastado com iluminação neon green e electric blue, tipografia pesada e padrão pontilhado de fundo.
